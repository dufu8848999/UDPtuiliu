

# Udp-streamVedio

基于 UDP 协议的低延迟屏幕实时传输系统，支持将屏幕内容实时传输到另一台设备进行显示。

## 项目简介

本项目实现了一个高效的屏幕实时传输解决方案，通过 UDP 协议将屏幕画面采集、压缩后传输到接收端。项目采用 LZ4 快速压缩算法，结合自定义的 UDP 数据包协议，能够在局域网环境下实现流畅的屏幕共享体验。

### 核心特性

- **低延迟传输**：采用 UDP 协议实现快速数据传输，最大程度降低传输延迟
- **高效压缩**：集成 LZ4 压缩算法，在保证压缩速度的同时减少网络带宽占用
- **灵活配置**：支持自定义传输分辨率、帧率等参数
- **多种工作模式**：支持发送端、接收端独立运行，满足不同场景需求
- **DLL 注入支持**：提供远程注入功能，可在目标进程中进行屏幕采集和传输

### 技术架构

```
发送端流程:
  屏幕采集 (DXGI) → 帧压缩 (LZ4) → 数据分片 → UDP 发送

接收端流程:
  UDP 接收 → 数据重组 → 解压缩 (LZ4) → 窗口显示
```

## 编译说明

### 环境要求

- Windows 10/11 操作系统
- Visual Studio 2022 或更高版本
- CMake 3.15 或更高版本（可选）
- DirectX 11 开发环境

### 编译步骤

1. 使用 Visual Studio 打开 `Demo/Demo.slnx` 解决方案文件
2. 选择 `x64` 平台和 `Release` 配置
3. 编译解决方案

编译成功后，可在 `Demo/Demo/x64/Release/` 目录下找到生成的可执行文件。

## 使用方法

### 命令行参数

程序支持以下命令行参数：

```
Demo.exe [模式] [参数]

模式:
  --sender <IP> <PORT>    启动发送端，指定目标 IP 和端口
  --receiver <PORT>       启动接收端，指定监听端口

示例:
  Demo.exe --sender 192.168.1.100 5000    // 向 192.168.1.100:5000 发送屏幕
  Demo.exe --receiver 5000                // 监听 5000 端口接收屏幕流
```

### 发送端使用

1. 运行程序并指定目标 IP 地址和端口
2. 程序将自动采集主屏幕内容
3. 采集画面将被压缩并通过 UDP 发送

### 接收端使用

1. 运行程序并指定监听端口
2. 程序将创建一个显示窗口
3. 接收并显示来自发送端的屏幕内容

### DLL 注入方式

对于需要远程采集屏幕的场景，可以使用注入功能：

1. 确保目标进程已运行
2. 使用注入工具将 DLL 注入到目标进程
3. 配置目标 IP、端口等参数

## 技术细节

### 数据包结构

每个 UDP 数据包包含以下内容：

- **包头**：包含帧 ID、总分片数、分片 ID、图像尺寸等信息
- **数据**：经过 LZ4 压缩的图像数据

### 分片策略

为了适应 MTU 限制，大尺寸帧会被分成多个小包进行传输：

```
单个数据包大小 = HEADER_SIZE + DATA_PER_PKT
总分片数 = ceil(压缩后数据大小 / DATA_PER_PKT)
```

### 时间同步

程序使用微秒级时间戳同步，确保接收端能够正确按帧率播放画面。

## 注意事项

1. 本程序仅在 Windows 平台下运行
2. 使用前请确保防火墙允许程序通过指定端口
3. 建议在局域网环境下使用以获得最佳效果
4. 高分辨率传输会占用较多网络带宽
